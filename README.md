# PortfolioHUB
Site portfolio pessoal integrado ao GitHub Pages.
Criado como projeto final com suporte do Google Gemini.

## Como contribuir
1. Fork o repositório
2. Crie uma branch: git checkout -b minha-feature
3. Faça suas alterações e commit: git commit -m 'feat'
4. Push: git push origin minha-feature
5. Abra um Pull Request

## Controle de Acesso
| Perfil | Permissão |
|---|---|
| Proprietário | Admin total |
| Colaborador | Write (PRs) |
| Visitante | Read (fork) |

## Segurança
- 2FA ativado para todos os colaboradores
- Branch main protegida (requer PR + review)
- Tokens com escopo mínimo necessário
- Arquivo SECURITY.md com políticas detalhadas
