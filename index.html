Práticas de
Segurança

Este projeto foi implantado seguindo as melhores práticas de segurança em GitHub.

🔐
2FA Ativado
Autenticação de dois fatores habilitada para proteção total da conta GitHub.
🌿
Branch Protection
Branch main protegida com regras de Pull Request obrigatório antes de qualquer merge.
🔑
Tokens Seguros
Personal Access Tokens com escopo mínimo e expiração configurada.
📋
SECURITY.md
Política de segurança documentada no repositório com processo de reporte de vulnerabilidades.
🚫
.gitignore
Arquivos sensíveis como .env e tokens bloqueados de qualquer commit acidental.

Auditado com IA
Configurações revisadas pelo Google Gemini para conformidade com melhores práticas de mercado.
